# Plan 04-01 — Matriz de validação Android QUAL-09 (estrutura + camada AUTOMATED-FAKE)

## Objective

Criar `04-ANDROID-VALIDATION.md`: uma matriz pequena, objetiva e auditável de
verificação Android para QUAL-09, com três camadas de evidência **rigidamente
separadas** (VERIFIED / AUTOMATED-FAKE / NOT VERIFIED). Este plano preenche a
camada AUTOMATED-FAKE a partir da evidência de testes já verde da Phase 3
(235 testes) e cria as linhas de cenário para os planos seguintes preencherem
as camadas VERIFIED (emulador, 04-02) e NOT VERIFIED (checkpoint humano).
