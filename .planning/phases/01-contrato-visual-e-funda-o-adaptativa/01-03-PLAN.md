<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Feature presentation data → shared primitives | Missing/error values must remain honest and not become fabricated measurements or global failure. |
| Visible technical value → OS clipboard | Only a deliberate action may cross the boundary, and the copied value must equal what the user sees. |
| Async clipboard completion → widget context | Late completion must not update disposed UI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-09 | Spoofing | `ToolStatusPanel` / `ToolMetric` | mitigate | Closed variants with icon+heading+body, null→Indisponível and tests forbidding numeric sentinels/fabricated zero. |
| T-01-10 | Information Disclosure | `CopyValueAction` | mitigate | Require explicit tap, copy exactly visible value, provide injectable writer, never auto-copy or add analytics. |
| T-01-11 | Repudiation | copy confirmation | mitigate | One specific `{Rótulo} copiado` SnackBar or canonical failure message; tests assert exactly one feedback event. |
| T-01-12 | Denial of Service | large text/action layout | mitigate | Wrap/vertical reflow, scroll, 48×48 targets and 360 px/text-scale-2 tests. |
| T-01-13 | Tampering | late clipboard completion | mitigate | Await writer then check `context.mounted` before ScaffoldMessenger access. |
| T-01-SC | Tampering | package supply chain | accept | SDK widgets/services only; no package or lockfile change is permitted. |
</threat_model>
