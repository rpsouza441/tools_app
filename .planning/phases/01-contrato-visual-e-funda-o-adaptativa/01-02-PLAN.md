## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Theme configuration → rendered meaning | Semantic roles must not misrepresent selection, error, disabled or focus through color alone. |
| Platform text scale → layout | Untrusted/variable user scaling must not hide actions or essential information. |
| Font configuration → offline app | Theme must not trigger an undeclared runtime font request. |
