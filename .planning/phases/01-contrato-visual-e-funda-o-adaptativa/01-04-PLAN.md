## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rendered UI → stored golden | A generated PNG becomes trusted regression evidence and must not normalize a defect. |
| Host rasterization → repository baseline | Platform/font/DPR differences can create misleading diffs. |
| Test fixture → claimed phase coverage | A fixture must exercise public production contracts rather than a parallel imitation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-15 | Spoofing | test-only gallery | mitigate | Compose public production primitives/themes/shell directly; prohibit copied lookalike implementations. |
| T-01-16 | Repudiation | host-dependent raster output | mitigate | Canonical Windows/Flutter 3.44.x, DPR 1, fixed physical sizes, settled animations and local fonts documented in tests. |
