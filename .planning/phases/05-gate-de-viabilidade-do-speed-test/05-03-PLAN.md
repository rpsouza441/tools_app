# Plan 05-03 — Elaboração do gate formal (05-SPEED-TEST-GATE.md) (bloco 3)

## Objective

Produzir o **artefato canônico da decisão** `05-SPEED-TEST-GATE.md` (D-01), aplicando a
regra de agregação objetivamente sobre a comparação (05-COMPARISON.md): `GO` só se
**todos** os critérios obrigatórios de **ao menos um** candidato forem `PASS`; qualquer
`FAIL`/`INSUFFICIENT` obrigatório impede GO (GATE-02). Registrar o veredito global no
vocabulário fixo `GO` / `NO-GO — ADIADO` / `NO-GO — DESCARTADO` (D-08), preferindo
`ADIADO` quando o bloqueio for ausência de evidência/termos/infra (D-09/D-18), e as
condições de reavaliação futura (D-19). Este bloco NÃO implementa speed test nem libera
SPD-* mesmo em caso de GO (D-20).

**Escopo negativo:** sem código, sem SDK, sem `lib/`/`android/`; sem forçar GO; sem
assumir NO-GO antes da evidência (D-17); sem iniciar milestone posterior.
