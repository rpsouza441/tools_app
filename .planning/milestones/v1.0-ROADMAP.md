# Milestone v1.0: Diagnóstico de Internet e Evolução da UI

**Status:** ✅ SHIPPED 2026-09-19
**Phases:** 1–5
**Total Plans:** 30 (11 + 4 + 7 + 4 + 4)

## Overview

Este milestone evoluiu o Tools App sem reescrita total: estabeleceu um contrato visual
adaptativo e acessível (Material 3, temas claro/escuro, responsividade), migrou com
segurança as três ferramentas existentes para a nova fundação, entregou o Diagnóstico de
Internet como um fluxo transparente/progressivo/cancelável/resiliente, comprovou o
comportamento em Android real e publicou documentação fiel ao implementado. Encerrou com um
gate formal de viabilidade do teste de velocidade cujo resultado foi `NO-GO — ADIADO`.

## Milestone Summary

**Decimal Phases:** nenhuma (sem inserções).

**Key Decisions:**

- Evoluir a UI em fatias compatíveis, sem reescrita total (Phase 1 fundação; Phase 2 migração).
- Conectividade/gateway/IP público/probes como adaptadores independentes injetáveis (sem `NetworkService`) — Phase 3.
- Exibir o método real de latência (HTTPS), nunca "ping"; ICMP sempre "indisponível" — Phase 3.
- Remover o probe TCP do gateway (mantendo o endereço) após validação física — Phase 4; app definido como resumo honesto da rede, não teste pass/fail.
- Padronizar o alinhamento dos estados do diagnóstico ao centro — Phase 4.
- Condicionar o speed test a infraestrutura legal/estável/testável; gate `NO-GO — ADIADO` — Phase 5.

**Issues Resolved:**

- Mensagem genérica de falha parcial corrigida para "Concluído com falhas parciais" (Phase 4).
- Preservação do contexto de rede ao retomar após troca 4G↔Wi-Fi (Phase 4, `refreshSnapshotOnly`).
- Semântica confusa do probe TCP do gateway — resolvida por remoção do probe (Phase 4).

**Issues Deferred:**

- Speed test (SPD-01..09): diferido — gate `NO-GO — ADIADO`; reavaliar por gatilhos em `05-SPEED-TEST-GATE.md §8`.
- Captive portal real (R3): NOT VERIFIED (requer rede com portal cativo real).
- Cancelamento e troca de rede mid-run: AUTOMATED-FAKE (lógica coberta por testes verdes).
- EVO-01..EVO-03: evoluções posteriores.

**Technical Debt Incurred:**

- A1: sem license grant escrito para `gstatic.com/generate_204` (URL permanece injetável; não bloqueante).
